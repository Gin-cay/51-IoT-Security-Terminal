# 51-IoT-Security-Terminal

基于51单片机的物联网安全终端，实现可靠串口通信、帧同步、异常检测与设备防护，是一套面向本科阶段的工业级嵌入式协议实践项目。

---

## 📌 项目概述

本项目为一套完整的 **51单片机串口通信协议栈 + 异常监测系统**，实现了帧同步、防干扰、数据校验、设备认证、看门狗防护、安全日志等功能。
项目采用 **状态机 + 分层协议** 设计，满足工业级串口通信的可靠性与安全性要求，可直接用于物联网终端设备开发。

### ✨ 核心特性
- ✅ **帧同步**：魔数(0xAA 0x55) + 版本号 + 长度字段，实现无粘包、可恢复的帧同步
- ✅ **异常防护**：超长帧丢弃、魔数错误、校验错误、超时重连等多维度错误统计
- ✅ **数据安全**：CRC32 校验 + 序列号防重放 + 设备白名单认证
- ✅ **状态管理**：维护模式切换、调试命令防护、非法指令统计
- ✅ **看门狗保护**：主循环喂狗，死机自动复位，保证设备在线率
- ✅ **传感器告警**：DS18B20温度监测、门磁入侵告警、异常数据上报
- ✅ **可扩展**：分层设计，可快速添加新命令、新传感器、新安全规则

# 51-IoT-Security-Terminal
基于51单片机的物联网终端安全监测与防御系统项目

## 项目简介
本项目以51单片机为核心，搭建物联网环境监测终端，实现温湿度数据采集与串口上传；同时针对终端弱口令、明文传输等常见安全漏洞，实现针对性防御方案，构建从终端采集到边缘校验的安全闭环。

## 硬件清单
- STC89C52RC 51单片机开发板
- DHT11 温湿度传感器
- USB数据线、杜邦线、面包板

## 项目进度
- ✅ Step1: 项目初始化，创建Hardware/Software文件夹
- ⏳ Step2: 终端数据采集与串口通信开发
- 🔜 Step3: 终端安全漏洞挖掘与防御实现
- 🔜 Step4: 边缘节点部署与可视化平台搭建
